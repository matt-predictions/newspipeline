# Roadmap

Items deferred from the modernization pass. Each entry lists motivation,
sketch, and a rough effort estimate. Pick up in priority order; the top
three are the most actionable.

---

## Tier 3 — north-star items deferred

### 1. Vector embeddings as the cluster cohesion gate
**Motivation.** The current `app/cluster/cohesion.py` already uses
text-embedding-3-small embeddings + mean-pairwise-cosine, so the
"primitive hash/keyword clustering" the audit flagged is partially
addressed. What's still missing:

- Embeddings only run on the *current* batch — same story split across
  two ingests becomes two clusters because the second run never sees
  the first's embeddings.
- The fall-back `cross_pair` matcher is keyword-only when the threshold
  walk produces nothing.

**Sketch.**
- Persist embeddings to `data/embeddings.parquet` keyed on
  `article_id`. Reuse across runs.
- Add a `cluster_id` column to the articles table; once an article
  joins a cluster, persist the assignment so future ingests can match
  back to existing clusters via centroid similarity.
- Replace `cross_pair` fallback with a tag-aware ANN lookup against the
  active cluster centroids (HNSW in `hnswlib`, or `numpy` brute force
  for now since the index fits in memory).

**Effort.** ~2 days. Affects `app/cluster/*` and one new
`app/cluster/store.py`. Has cascading test impact (the cohesion gate is
already well-instrumented).

### 2. Persona long-term memory
**Motivation.** Aisha shouldn't reach for the same ER analogy three runs
in a row. Maria shouldn't price every story at "60% no way it's even."
Long-term memory keeps the panel sounding like real people across runs.

**Sketch.**
- SQLite-backed `persona_memory` table: `(persona_id, run_id, takeaway,
  topic_tags, ts_iso)`. One takeaway per persona per run, generated by
  a short follow-up prompt right after JJJ ("In one sentence, what's
  Aisha walking away thinking?").
- At the start of each new debate, inject the persona's last 3
  takeaways into their card as a "RECENT TAKES" block.
- Tag-based filter so we only inject takeaways from similar topics
  (avoid Aisha quoting her geopolitics take in a healthcare story).

**Effort.** ~1.5 days. New table, two prompts, light wiring in
`conversation.py`. Could be A/B'd by adding a `--persona-memory` flag.

### 3. DAG / Prefect-style orchestration with retries
**Motivation.** `pipeline.py` is a linear `await` chain; if `brief`
fails on a retryable 429 we want exponential backoff *at the step
level*, not buried inside the LLM client wrapper. Independent steps
(polymarket + brief) could run in parallel.

**Sketch.**
- Build a tiny in-process DAG runner with `asyncio` futures. Each step
  declares its dependencies (`{polymarket, brief}` for the panel,
  `{panel}` for jjj, etc). Steps with no deps overlap.
- Move retry policy to step config (`Step(retry=ExponentialBackoff(...))`).
- Manifest already records per-step; the DAG runner just becomes the
  thing that calls `manifest.record`.

**Effort.** ~3 days. Touches `app/story/pipeline.py` extensively but is
mostly mechanical once the DAG primitives are in place. Defer until the
linear pipeline shows actual bottlenecks (parallel poly+brief saves
~3-5s).

### 4. Langfuse / Helicone trace integration
**Motivation.** The local manifest is great for one-off debugging but
we want shareable LLM traces with timings, prompt diff, evals attached.

**Sketch.**
- Add `LANGFUSE_PUBLIC_KEY` / `LANGFUSE_SECRET_KEY` to settings.
- Wrap `openai_chat_with_retry` and `anthropic_call_with_retry` so each
  call publishes a span. Manifest events become trace metadata.
- Eval results (consensus_quality.py, style.py) attach as scores.

**Effort.** ~1 day. SDK is cheap to wire; the work is mostly in
deciding what gets a span vs metadata.

### 5. MCP server exposing each persona as a callable tool
**Motivation.** Lets a downstream agent ask "Aisha, what would you bet
on this?" without spinning up the full panel. Also makes the personas
addressable from Claude Desktop / Cursor.

**Sketch.**
- `app/mcp/server.py` exposes one tool per agent: `ask_aisha`,
  `ask_devon`, ..., `ask_panel` (runs the full 5-persona debate).
- Reuse `app.agents._loader.AgentSpec` + the conversation primitives.

**Effort.** ~1 day for the single-shot tools, +1 day for the full panel
tool (needs streaming).

### 6. Multi-modal output pipeline (scene-by-scene)
**Motivation.** Right now the hero PNG + one Higgsfield video is the
visual deliverable. A multi-scene pipeline (3-5 cuts, scripted
narration, intercuts) would be a meaningful step up.

**Sketch.**
- Storyboarding step between JJJ and hero: takes the brief + panel
  transcript, returns a `Storyboard` (3-5 scenes, each with image
  prompt + camera move + narration).
- Render each scene's hero image (parallel), submit each as a separate
  Higgsfield job (parallel), stitch with `ffmpeg`, layer in narration
  via `gpt-4o-audio-preview` or ElevenLabs.

**Effort.** ~5 days. Biggest deferred item — full new output type and a
new render pipeline. Worth doing only after the single-video pipeline
is proven in production.
